# 🛒 Zaptro – E-Commerce Frontend (React)

Zaptro is a responsive e-commerce frontend built with React.  
It includes product listing, filtering, pagination, cart, and authentication UI.

## 🚀 Features

- Product listing from API (DummyJSON)
- Search, Category, Brand & Price filters
- Pagination
- Product details page
- Add to Cart, Update Quantity, Remove Item
- Cart summary & checkout UI
- Authentication UI using Clerk
- Responsive design with Tailwind CSS
- Toast notifications
- Lottie animations for empty & not-found states

## 🛠 Tech Stack & Libraries

### Core
- React (Vite)
- React Router DOM

### State Management
- Context API

### Styling
- Tailwind CSS
- React Icons
- Lucide React (icons)

### Data & API
- Axios

### Authentication
- Clerk (@clerk/clerk-react)

### UI Enhancements
- React Toastify (notifications)
- Lottie React (animations)
- Slick Carousel (react-slick + slick-carousel)
